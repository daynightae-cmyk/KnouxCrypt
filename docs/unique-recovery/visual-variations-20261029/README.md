# Recovered Android visual alternatives and prompt sources

This is a provenance archive, **not a set of approved production UI references**. Original files were copied without edit from the file-level hash-verified 2026-11-02 snapshot of the planning checkout.

- This directory preserves **154 files** not byte-identical to any tracked `main` file at recovery time: **5 alternate PNGs**, 136 text assets, 8 PowerShell scripts, 4 Markdown notes and one JSON manifest, total 7,011,521 bytes.
- **45 PNG images** from the same untracked visual tree were skipped as exact SHA-256 duplicates of PNGs already tracked on `main` (including all 44 primary screen PNGs).
- Two ZIP containers (`KNOUX_CRYPT_ANIMA_V5_DELIVERY.zip`, `REPO_AGENT_MISSIONS.zip`) totaling 70,336,288 bytes were deliberately omitted from Git because inner-content duplication was not independently verified; originals remain under the K-drive snapshot and planning checkout.
- Alternate concepts must **not** replace approved app visuals automatically. The live canonical screen/task registry remains unchanged.
- Scripts are historical source material; **do not execute** them without auditing environmental assumptions and side effects.
- No app logic, cryptography, Gradle, Electron files or active agent worktrees changed in this recovery.
